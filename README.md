# Кейс 3 — класс `WORKER`

Учебная консольная программа на C++17 для учета работников.

## Что реализовано

- класс `WORKER` вынесен в отдельные файлы `Worker.h` и `Worker.cpp`;
- поля: фамилия и инициалы, должность, зарплата, год приема;
- конструктор по умолчанию, параметризованный конструктор и деструктор;
- методы получения, изменения и вывода полей;
- динамический контейнер `std::vector<WORKER>`;
- расчет стажа по текущему году;
- вывод фамилий работников со стажем строго больше заданного порога;
- сообщение, если подходящие работники отсутствуют;
- проверка некорректной зарплаты, пустых строк и года приема;
- автоматические тесты в `tests/WorkerTests.cpp`.

## Сборка в Visual Studio

1. Откройте папку `worker_cpp` в Visual Studio Community.
2. Visual Studio обнаружит `CMakeLists.txt`.
3. Выберите конфигурацию `x64-Debug` или `x64-Release`.
4. Запустите цель `worker_app`.
5. Для проверки выберите цель `worker_tests` или запустите тесты CMake.

## Пример сценария проверки

Введите несколько работников, например:

```text
Иванов И. И. | Программист | 150000 | 2020
Петров П. П. | Аналитик | 120000 | 2024
```

Если текущий год — 2026, при пороге `3` программа выведет Иванова, а Петрова не выведет.

## Ограничения учебной версии

Данные не сохраняются в файле или базе данных и вводятся заново при каждом запуске. Для реальной информационной системы следующим этапом можно добавить CSV/SQLite, авторизацию и разграничение доступа.
