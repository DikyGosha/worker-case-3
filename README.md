# Кейс 3 — класс `WORKER`

Учебная консольная программа на C++17 для учета работников.

## Что реализовано

- класс `WORKER` вынесен в отдельные файлы `Worker.h` и `Worker.cpp`;
- поля: фамилия и инициалы, должность, зарплата, год приема;
- конструктор по умолчанию, параметризованный конструктор и деструктор;
- методы получения, изменения и вывода полей;
- динамический контейнер `std::vector<WORKER>`;
- расчет стажа по текущему году;
- вывод фамилий работников со стажем строго больше заданного порога;
- сообщение, если подходящие работники отсутствуют;
- проверка некорректной зарплаты, пустых строк и года приема;
- автоматические тесты в `tests/WorkerTests.cpp`.
